TenderGuard Africa

Agentic AI decision support for transparent and auditable public tender evaluation.

Interactive Browser Demonstration

This browser demonstration uses predefined synthetic procurement data to illustrate the TenderGuard Africa evaluation workflow.

The browser simulates evaluation steps and report generation. It does not execute the AI model or communicate directly with the MCP servers.

The fully functional agentic workflow runs locally using Qwen3, LangGraph, and MCP through the Python application available in the public GitHub repository.

Architecture

Agentic AI + MCP

  • Qwen3 1.7B open-weights model
  • LangGraph stateful orchestration
  • Custom Procurement MCP server
  • 5 procurement MCP tools
  • Borrowed Filesystem MCP server
  • Named human approval gate
  • Auditable tool execution
  • Evidence-based decision support
  • Human-controlled final procurement decisions

The Python application implements the agentic workflow. This browser provides its visual demonstration.

Evaluation Evidence

9 PASS · 1 Known FAIL

TenderGuard includes ten documented evaluation scenarios covering agent execution, MCP tool discovery, procurement compliance, price comparison, supplier-data checks, human approval, filesystem access controls, and model repeatability.

Nine scenarios passed in the documented evaluation run. The unresolved scenario concerns image-only or scanned PDF extraction.

OCR is not currently implemented in the prototype. The demonstration uses structured synthetic procurement records.
